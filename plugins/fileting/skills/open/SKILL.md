# 파일팅 열기

1. 맥 또는 윈도우인지 확인한다. 둘 다 아니면 "아직 맥과 윈도우에서만 돼요"라고 알리고 멈춘다.

2. Node.js가 있는지 확인한다: `node --version`. 없으면 https://nodejs.org 에서 LTS 버전을 설치하라고 안내하고 멈춘다.

3. 파일팅을 켠다. 이 스킬의 Base directory(위에 표시된 `.../skills/open`) 기준으로 `../../app/bin/fileting.js` 를 실행한다. 서버를 뒤에서 켜두고 크롬까지 열어준다. 이미 켜져 있으면 크롬만 연다.

```bash
node "<Base directory>/../../app/bin/fileting.js" --detach
```

4. 사용자에게 짧게 안내한다:
   - **"작은 창으로 띄우기"**를 누르면 다른 앱 위에 떠 있어요.
   - 왼쪽(🗑️, ←)은 휴지통으로 버리기, 오른쪽(📌, →)은 남기기, ↩(Z)는 되돌리기예요.
   - 맥이 "다운로드 폴더 접근"을 물어보면 허용해야 해요. 윈도우는 데스크탑·문서가 OneDrive 폴더여도 알아서 찾아요.
   - 모르는 파일은 터미널 `claude`가 로그인돼 있으면 AI가 설명해줘요(사용자 본인 구독 사용량을 조금 써요).
